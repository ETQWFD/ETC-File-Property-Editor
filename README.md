# ETC File Property Editor

**v4.1** · 修改类工具 · 开发者: etc · 语言: English (United States) · 文件说明: 改文件属性

一款纯 Windows 原生（C++ / Win32）文件属性修改工具：选择任意文件，可视化修改**文件说明、类型、文件版本、产品名称、产品版本、版权、公司、语言、修改日期与图标**，点击「确认转换」后输出到程序目录下的 `etc` 文件夹。

## 功能

- 文件说明（FileDescription）、类型（FileType）直接修改
- 文件版本（FileVersion）、产品版本（ProductVersion）双字段写入
- 产品名称（ProductName）、版权（LegalCopyright）、公司（CompanyName）
- 语言：内置英 / 中 / 日 / 韩 / 德 / 法 / 西等 11 种 LCID
- 修改日期：选择文件自动带出原时间，可手动修改或一键「同步」为当前时间
- 自定义图标：选择 .ico，转换后文件的图标即为你选中的图标
- 转换在独立工作线程执行：进度条实时推进，界面不卡顿
- 转换完成自动弹出完成窗口
- 支持 EXE / DLL / OCX / SYS / CPL 等 PE 文件；非 PE 文件同样支持修改修改时间

## 使用

1. 点击「浏览文件…」或直接把文件拖进窗口
2. 在右侧面板填写属性（需要换图标就再选一个 .ico）
3. 点击「确认转换」，进度条走完弹出完成窗口
4. 新文件保存在程序目录下的 `etc` 文件夹，原文件保持不变
