FEATURES

能改什么

选择任意文件，在右侧面板填写属性，点击「确认转换」，新版文件立即输出到程序目录下的 etc 文件夹。修改的是真实资源信息，不是伪装。

文件说明 / 类型

FileDescription 与 FileType 字段直接修改，资源管理器「详细信息」立即生效。

文件 / 产品版本

FileVersion 与 ProductVersion 双版本字段，同时写入固定版本号与字符串。

产品名称 / 版权 / 公司

ProductName、LegalCopyright、CompanyName 一次填齐，版权归属一目了然。

语言设置

内置英/中/日/韩/德/法/西等 11 种语言，写入对应 LCID 与代码页。

修改日期自动同步

选择文件后自动带出原修改时间，可手改，也可一键「同步」为当前时间。

自定义图标

选择任意 .ico 图标，转换后的文件在资源管理器中显示为你选中的图标。

进度条 · 不卡界面

转换在独立工作线程中执行，进度条实时推进，窗口始终保持响应。

完成弹窗提醒

转换完成自动弹出完成窗口，输出路径一目了然，无需手动查找。

HOW IT WORKS

三步完成

选择文件

点击「浏览文件…」或直接把文件拖进窗口。支持 EXE / DLL / OCX / SYS / CPL 等任意文件，非 PE 文件同样可修改修改时间。

设置属性

在右侧面板填写文件说明、版本、产品、版权、语言与修改日期；需要换图标就再选一个 .ico，点「同步」可把日期对齐到当前时间。

确认转换

点击「确认转换」，进度条走完即弹出完成窗口。新文件保存在程序目录下的 etc 文件夹，原文件原封不动。
